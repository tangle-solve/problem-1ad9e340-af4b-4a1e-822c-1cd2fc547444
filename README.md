### ALGO-000122: Deterministic polynomial-time Exact Matching
- **Subfield:** Graph algorithms, parallelism, and dynamic computation
- **Open:** Given a graph with red and blue edges and an integer \(q\), determine whether a perfect matching uses exactly \(q\) red edges, deterministically in polynomial time.
- **Status:** Randomized polynomial-time algorithms are known; general deterministic polynomial time remains open.
- **Type:** theory
- **Why:** Tests the power of algebraic randomization in a natural constrained matching problem.
- **Key works:** Papadimitriou and Yannakakis (1982), *The Complexity of Restricted Spanning Tree Problems*; Mulmuley, Vazirani, and Vazirani (1987).
- **Related:** Resource-constrained optimization—exact-budget assignments.
